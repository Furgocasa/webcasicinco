## 🎨 ESTÁNDAR DE DISEÑO OBLIGATORIO

### Paleta de Colores (FIJA)
- **Negro principal:** `#1d1d1f` (CTAs, títulos, elementos importantes)
- **Gris oscuro:** `#424245` (texto de cuerpo)
- **Gris medio:** `#6e6e73` (texto secundario)
- **Gris claro:** `#86868b` (metadatos, etiquetas)
- **Gris líneas:** `#f0f0f2`, `#e5e5e7` (separadores)
- **Fondo:** `#ffffff`, `#fafafa`

### Elementos Prohibidos
❌ **NO usar azul** en CTAs o elementos principales  
❌ **NO usar gradientes** (solo colores sólidos)  
❌ **NO usar sombras** en botones o cards  
❌ **NO usar emojis** excesivos (máximo 1-2 por email)  
❌ **NO usar colores llamativos** (rojos, verdes, amarillos)

### Elementos Obligatorios
✅ Tipografía: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`  
✅ CTAs en negro `#1d1d1f` con `border-radius: 4px`  
✅ Espaciado generoso (padding mínimo 40px en laterales)  
✅ Líneas sutiles para separadores  
✅ Logos en versión blue/dark (nunca white salvo header oscuro)
