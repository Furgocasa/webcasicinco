## 🚀 Cómo Usar con Outlook

### Opción 1: Copiar y Pegar
1. Abre el archivo HTML en un navegador
2. Selecciona todo (Ctrl+A / Cmd+A)
3. Copia (Ctrl+C / Cmd+C)
4. En Outlook: Nuevo Email → Pega en el cuerpo
5. ✅ Listo para enviar

### Opción 2: Importar HTML
1. Outlook → Nuevo Email
2. Insertar → Archivo Adjunto → Insertar como Texto
3. Selecciona el archivo .html
4. ✅ Se importará con formato

### Opción 3: Firma HTML (para envíos masivos)
1. Outlook → Opciones → Firmas
2. Nueva firma → Pega el HTML
3. Usa la firma en tus emails
