## 📞 **AYUDA RÁPIDA**

### **Error durante indexación:**
```
1. Ve a: COMANDOS_UTILES.md → Sección "Solución de Problemas"
2. Ejecuta: supabase/verificar_integridad_datos.sql
3. Revisa: SISTEMA_INDEXACION_PROFESIONAL_COMPLETO.md
```

### **Números no cuadran:**
```
1. Lee: ANTES_Y_DESPUES.md (explica por qué)
2. Ejecuta: supabase/verificar_integridad_datos.sql
3. Verifica: CONEXION_FRONTEND_BACKEND.md → Sección "Números consistentes"
```

### **Quiero hacer deployment:**
```
1. Lee: DEPLOY_AWS.md (paso a paso)
2. Verifica: VERIFICAR_VARIABLES_AWS.md
3. Ejecuta: VERIFICAR_PRODUCCION.md (checklist)
```

### **Configurar nuevo entorno:**
```
1. Lee: CONFIGURACION_COMPLETA.md
2. Copia: .env.example → .env.local
3. Ejecuta: npm install && npm run dev
```
